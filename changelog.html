Changelog

Version history

Every release, and what changed in it.

1.0

Initial release

Welcome to Naimap. This is our first release, and it's a complete one.

  • Full native mind-mapping canvas — unlimited maps and nodes
  • Six starting templates: Blank, Brainstorm, Project Planning, Meeting Notes, Study Topic, SWOT Analysis
  • Rich node content: notes, links, images, videos, and documents
  • Full undo/redo on every action
  • Auto Arrange smart layout
  • Search across every node in a map
  • Presentation Mode, free-roam
  • Guided Presentation with a custom Presentation Path and private Presenter Notes (Naimap Pro)
  • Export to PNG and JSON (free), PDF and Draw.io (Naimap Pro)
  • Share, Save to Files, and native printing
  • VoiceOver and Dynamic Type support throughout; Light and Dark Mode
  • iPhone and iPad, including an adaptive Node Details inspector on iPad
  • Zero network access, zero tracking
